This site is static HTML, built from Markdown and served from GitHub Pages. The source is at [github.com/PSRahul/PSRahul.github.io](https://github.com/PSRahul/PSRahul.github.io).

## Stack

- **Framework:** [Astro](https://astro.build/), starting from the [AstroPaper](https://github.com/satnaing/astro-paper) theme.
- **Styling:** [Tailwind CSS](https://tailwindcss.com/).
- **Fonts:** [Inter](https://rsms.me/inter/) for text, [Google Sans Code](https://fonts.google.com/specimen/Google+Sans+Code) for code.
- **Math:** [KaTeX](https://katex.org/), rendered at build time.
- **Search:** [Pagefind](https://pagefind.app/), a static index that runs in the browser.
- **Comments:** [Giscus](https://giscus.app/), backed by GitHub Discussions.
- **Analytics:** [GoatCounter](https://www.goatcounter.com/). No cookies, no personal data.
- **Hosting:** GitHub Pages, deployed by GitHub Actions on every push.

## Publishing

Posts follow [POSSE](https://indieweb.org/POSSE): publish here first, then syndicate to Substack and Medium with a link back. Posts that only live on those platforms are pulled in from their RSS feeds at build time.
